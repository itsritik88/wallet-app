
# Wallet App 💳  
A full-stack application for managing digital wallets, transactions, and financial tracking.



## Features ✨  
- **Secure authentication** (JWT/OAuth-ready structure)  
- **Transaction management** (CRUD operations)  
- **Balance tracking** (Real-time updates)  
- **Responsive UI** (Mobile-first design)  
- **API-driven architecture** (Separation of concerns)

## Installation ⚙️  
1. **Clone the repository**  git clone https://github.com/itsritik88/wallet-app.git

2. **Backend setup**  
    cd backend
    npm install
    npm start

3. **Frontend setup**  
cd ../frontend
npm install
npm start

## Configuration 🔧  
Create `.env` files in both frontend and backend directories with appropriate environment variables.
